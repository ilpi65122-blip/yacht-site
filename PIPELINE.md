# Current Pipeline

Traced from a recent piece of work on 2026-11-12: **the yachts website + CRM**, idea to result.

## Stages, in order

1. **Idea** — my own, no external brief.
2. **Write one big prompt** describing everything I wanted.
3. **Send the prompt to Claude.**
4. **Claude builds the website.**
5. **Test the website.** → if it needs work, ask for "change this and that" → **loop back to step 4** → test again, until it passes.
6. **CRM — same path:** big prompt → Claude builds → test → fix → **loop**, until it passes.
7. **Lands in a local folder** (not pushed, not deployed).

## Loops and waits

- **Loop:** the build → test → fix cycle, run on the website and again on the CRM. It's the only place work changes direction.
- **Waits:** none — it flowed straight through, idea → prompt → build → test → fix → local folder.

## In one line

Idea → one big prompt → Claude builds → I test → fix loop → repeat for the CRM → finished files in a local folder.
